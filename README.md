# paprika

Archivo web público de recetas exportadas de Paprika.

## Estado

Versión: **main actual** (sin versión semántica publicada).

## Funciones

- Presenta las recetas en formato web.
- Conserva el contenido exportado y sus estilos.
- Permite consultar el recetario desde un navegador.
- Funciona como sitio estático sin servidor ni compilación.

Web: <https://ricardoyf.github.io/paprika/>
